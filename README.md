# Форма управления учётными записями

Тестовое задание: форма на **Vue 3**, **TypeScript**, **Pinia**, **Vite**, **Tailwind CSS**.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Превью продакшн-сборки: `npm run preview`.

## CI/CD (GitHub Actions)

При пуше в `main` запускается workflow: сборка (`npm ci`, `npm run build`) и деплой на **GitHub Pages**. 

## Соответствие ТЗ

- **Заголовок и кнопка «+»** — добавление новой учётной записи в конец списка.
- **Подсказка** — текст про разделитель `;` для поля «Метка».
- **Список записей** с колонками: Метки, Тип записи, Логин, Пароль, кнопка удаления.
- **Метка** — необязательное поле, макс. 50 символов; при сохранении преобразуется в массив `[{ text: "элемент" }, ...]` по разделителю `;`.
- **Тип записи** — выпадающий список: LDAP (пароль скрыт, в хранилище `null`) / Локальная (пароль отображается и сохраняется).
- **Логин** — обязательное, макс. 100 символов.
- **Пароль** — обязательное при типе «Локальная», макс. 100 символов.
- **Валидация** по потере фокуса (текстовые поля) и при смене типа (селект); при ошибках — красная обводка; при успехе — сохранение в Pinia.
- **Персистентность** — данные хранятся в Pinia с `pinia-plugin-persistedstate` (localStorage), после перезагрузки страницы список восстанавливается.

## Структура

- `src/stores/accounts.ts` — Pinia-стор учётных записей (нормализованные данные, персист).
- `src/composables/useAccountForm.ts` — логика формы (локальное состояние, валидация, синхронизация со стором).
- `src/components/AccountManager.vue` — UI формы по макету.
- `src/types/account.ts` — типы и лимиты.
- `src/utils/labels.ts` — преобразование метки: строка ↔ массив `{ text }`.
- `src/utils/validation.ts` — правила валидации полей.
